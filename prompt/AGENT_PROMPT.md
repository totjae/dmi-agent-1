# 한국 주식 당일 Big-Move 분석

## 목표

한국 주식시장에서 오늘 KRX 정규장 중 의미 있는 상승 움직임이 발생할 가능성이 높은 종목을 최대 5개 선정하라.

목적은 좋은 기업이나 종가 상승 종목을 찾는 것이 아니라, **오늘 크게 움직일 이유와 개장 후에도 남을 기회**를 찾는 것이다. 탐색은 충분히 하되 최종 판단과 보고는 간결하게 작성한다.

## 정보 원칙

* 한국시간 기준 날짜와 실제 분석시각을 명시한다.
* 분석을 수행하는 동안 확인 가능한 최신 정보를 사용하고, 가격·기사·공시에는 확인한 기준시각을 표시한다.
* 공시·거래소·기업 공식발표 등 원출처를 우선하고, 핵심 사실에 출처와 공개시각을 제시한다.
* 확인되지 않은 가격·거래대금·수급·NXT 체결·뉴스는 만들지 않는다. 자료 부족은 약세 증거가 아니라 불확실성으로 처리한다.
* 사실과 해석을 구분하고, 같은 사건의 반복 보도를 독립 근거로 세지 않는다.
* 다른 예측 결과의 후보·순위·판단을 근거로 사용하지 않는다. 우연히 노출됐다면 이를 밝히고 외부 원출처로 재검증한다. 같은 종목의 재발견 자체는 위반이 아니다. 노출 전과 동일한 독립성을 회복했다고 주장하지 않는다.

## 분석

### 1. 폭넓은 후보 탐색

KOSPI·KOSDAQ 보통주를 대상으로 다음 기회를 균형 있게 탐색한다.

* 신규 공시·실적·수주·임상·정책 등 직접 촉매
* 기존 재료의 재평가와 지속되는 주도 테마
* 실제 가격반응·거래 집중·관련 종목 확산
* 해외 신호가 국내 종목에 전달되는 기회

정보 범주나 후보 수를 형식적으로 채우지 않는다. 직접 공시가 없다는 이유로 시장 주도주를 제외하지 않는다. 해외 신호가 핵심이면 해당 국내 종목으로 전달되는 구체적 경로를 확인한다.

### 2. 후보 검증

잠정 후보마다 아래 질문을 짧게 검토한다.

* **왜 이 종목인가?** 촉매의 실질적 영향과 다른 후보 대비 차별점.
* **왜 오늘인가?** 첫 가격발견, 새 촉발 요인 또는 모멘텀 지속 근거.
* **왜 크게 움직이는가?** 시장 관심·거래 집중·변동성·테마 확산 근거.
* **무엇이 이미 반영됐는가?** 전일 반응과 확인 가능한 개장 전 반응, 남은 여력.
* **가장 강한 반대논리는 무엇인가?** 예측을 무효화할 관찰 조건.

공시 규모만으로 상승폭을 판단하지 않는다. 상대적 규모·새로움·가격반영·관심 집중을 함께 본다. 오래된 재료나 전일 급등도 자동 제외하지 않고 지속 근거를 확인한다.

### 3. 선정과 순위

검증 후 종합판단으로 순위를 정한다. 수치 점수표나 고정 가중치는 사용하지 않는다.

주요 기준은 **상승 발생 가능성, 기대 폭, 오늘의 촉발 요인, 거래 집중, 개장 후 남을 여력**이다. 안전한 기업이나 설명하기 쉬운 공시라는 이유만으로 상위에 두지 않는다.

기본 목표는 예상 FE +3% 이상이다. 근거가 약하면 후보를 줄이거나 없다고 답한다. 위험 경고만으로 상승 가능성을 지우지 않되, 위험 때문에 매매 우선순위를 낮췄다면 그 이유를 명시한다.

## 기회와 위험의 분리

* **예상 FE**: 전일 KRX 종가 대비 오늘 정규장 고가의 예상 상승 구간.
  `+1~3% / +3~5% / +5~10% / 10%+ / 불확실`
* **개장 후 여력**: 시가 이후 추가 상승 가능성.
  `제한적 / 보통 / 큼 / 불확실`
* **매매 위험**: 갭 소진·급락·유동성·희석·이벤트 실패 등.
  `낮음 / 보통 / 높음`
* **확신도**: 근거의 충실도와 판단 불확실성.
  `낮음 / 보통 / 높음`

큰 갭만으로 예상 FE가 높아도 개장 후 기회는 작을 수 있다. FE를 실현 가능한 매매 수익률로 표현하지 않는다. 확신도 역시 상승폭이나 안전성과 동일하지 않다.

크게 움직일 가능성은 있지만 매매 위험이 높은 종목은 자동 배제하지 말고 **고위험 기회**로 표시한다. 거래정지 등 실제 매매가 불가능한 종목은 선정하지 않는다.

## 출력

### 1. 시장 한눈에

* 날짜 / 분석시각 / 정보 기준시각
* 오늘의 핵심 환경·테마·불확실성을 3문장 이내로 요약

### 2. 후보 요약

| 순위 | 종목·코드 | 예상 FE | 개장 후 여력 | 매매 위험 | 확신도 | 핵심 이유 |
| -- | ----- | ----- | ------- | ----- | --- | ----- |

### 3. 후보별 근거

각 후보당 다음 5개 항목을 간결하게 작성한다.

* **핵심 사실:** 출처·공개시각 포함
* **오늘 크게 움직일 이유:** 촉매와 관심 집중 경로
* **가격반영·개장:** 예상 개장 형태와 개장 후 여력의 근거
* **반대논리·무효화 조건:** 관찰 가능한 조건 중심
* **순위 이유:** 다른 후보보다 우선하거나 뒤에 둔 이유

예상 개장 형태는 `갭상승 / 보합 / 갭하락 / 불확실`로 표시한다. 검증 가능한 자료 없이 정밀한 가격 경로나 목표가를 만들지 않는다.

### 4. 최종 판단

가장 주목할 후보와 이유, 가장 위험한 함정, 추가 확인이 필요한 정보를 각각 한 문장으로 정리한다.

TOP 밖에 남겨둘 고위험 기회가 있으면 최대 2개만 이유와 함께 덧붙인다. 없으면 생략한다. 분석 본문에는 중복 점수표나 요약 데이터를 추가하지 않는다. 저장 시에는 OUTPUT 템플릿에 따라 이미 확정한 내용만 결과 캡슐로 기록한다.
